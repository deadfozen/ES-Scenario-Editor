# ES Scenario Editor

**ES Scenario Editor** - редактор для создания модификации игры «Бесконечное лето» (*Everlasting Summer*), написанной на движке Ren’Py.

Мы в **WikiVerse Team** работаем над этим проектом, с целью упростить процесс создания, редактирования и организации сценариев, а также работы с игровыми ресурсами.

### Возможности

- **Редактирование сценариев** - удобная работа с кодом Ren’Py и файлами игровых сценариев
- **Каталог игровых ресурсов** - библиотека фонов, спрайтов, CG и других материалов с возможностью предпросмотра
- **Подсветка синтаксиса** - визуальное выделение элементов кода для более комфортной работы
- **Управление проектом** - работа с файлами и структурой модификации в одном приложении
- **Документация** - встроенные справочные материалы для освоения создания модификации от самого начала до написание сложнейших Python-скриптов

### Цель проекта

ES Scenario Editor создаётся как единое рабочее пространство для мододелов «Бесконечного лета», которое поможет сделать разработку модификаций удобнее, организованнее и доступнее.

Проект находится в активной разработке. Возможности редактора будут расширяться по мере развития проекта.
