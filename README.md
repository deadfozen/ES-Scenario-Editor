# ES Scenario Editor (ESSE)

**ES Scenario Editor (ESSE)** — редактор сценариев для создания модификаций игры «Бесконечное лето» (*Everlasting Summer*) на движке Ren’Py.

Проект разрабатывается в рамках **WikiVerse Team** с целью упростить процесс создания, редактирования и организации сценариев, а также работы с игровыми ресурсами.

### Возможности

* **Редактирование сценариев** — удобная работа с кодом Ren’Py и файлами игровых сценариев.
* **Каталог игровых ресурсов** — структурированная библиотека фонов, спрайтов, CG и других ассетов с возможностью предварительного просмотра.
* **Подсветка синтаксиса** — визуальное выделение элементов кода для более комфортной работы.
* **Управление проектом** — работа с файлами и структурой модификации в одном приложении.
* **Документация** — встроенные справочные материалы для освоения редактора и его возможностей.

### Цель проекта

ESSE создаётся как единое рабочее пространство для мододелов «Бесконечного лета», которое поможет сделать разработку модификаций удобнее, организованнее и доступнее.

Проект находится в активной разработке. Возможности редактора будут расширяться по мере развития проекта.

**ES Scenario Editor — инструменты для создания собственных историй.**
