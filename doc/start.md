# Как создать мод для Бесконечного Лета | База

## Создание мода

Чтобы начать делать мод, первым делом создайте файл с расширением `.rpy`. Откройте его в любом текстовом редакторе, и можно приступить к работе

### Написание кода

По своему устройству Ren'Py очень напоминает Python. Если вы уже знакомы с этим языком, то разбираться в синтаксисе будет несложно. Весь код здесь строится на блоках и командах внутри них.

```text
Блок:   
    Команды
    
Блок:
    Команды
```

Самое важное правило — соблюдать одинаковые отступы для всех команд в одном блоке. Обычно используют четыре пробела. Хотя в редакторах удобно нажимать Tab, сам движок Ren'Py табуляцию не любит и часто выдает из-за нее ошибки. Чтобы избежать проблем, лучше всего настроить в своем редакторе автоматическую замену знаков табуляции на пробелы.

### Объявление мода

Для того чтобы игра увидела ваш мод и добавила его в общий список, его нужно правильно объявить. Без этого шага мод просто не отобразится в меню. В начале файла пишется блок `init`, где указывается техническое название мода и то имя, которое увидят игроки.

```renpy
init:
    $ mods["my_mod"] = "Мой мод"
```

Техническое название используется движком для запуска. Оно должно быть уникальным, чтобы не возникло конфликтов с другими модами, и его лучше писать латиницей. Название для пользователей может быть любым, в том числе на кириллице. Сразу после этого нужно создать метку или лэйбл с тем же техническим названием. Именно с этого места игра начнет считывать ваш сценарий и команды.

```renpy
init:
    $ mods["my_mod"] = "Мой мод"
    
label my_mod:
    "Действия"
```

Если вы хотите выделить свой мод в списке, можно изменить оформление текста.  С помощью специальных тегов в строке названия настраивается шрифт, его цвет и размер. Вы можете использовать свои файлы шрифтов в форматах .ttf или .oft, задать нужный оттенок через цветовой код или сделать буквы крупнее. Все эти настройки прописываются прямо в блоке объявления мода.

```renpy
init:
    $ mods["my_mod"] = "{font=mods/my_mod/fonts/название шрифта.ttf}{color=#45b39d}{size=50}Мой мод{/size}{/color}{/font}"
```
